DJI Project — Wyodrębnione dane

Zawartość:
- docs/: Wyodrębnione dokumenty i projekty (Mini 4 Pro, RC2)
- hacks/: Kod związany z DroneHacks (aplikacja Android i skrypty reverse-engineeringowe)

Cel projektu:
- Skonsolidować wszystkie zasoby dotyczące dronów DJI w jednym miejscu
- Ułatwić dalszy rozwój, testy i analizę (reverse-engineering, firmware, protokoły)

Jak użyć:
1. Przejrzyj pliki w projects/dji-project/docs i projects/dji-project/hacks
2. Jeśli chcesz uruchomić aplikację Android (dronehacks), otwórz katalog app/ i skorzystaj z Gradle

Uwagi o bezpieczeństwie:
- Nie publikować poufnych danych (klucze, tokeny, pliki binarne z firmware) bez przeglądu.
